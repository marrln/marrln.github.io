Image Toolkit - C++

A C++17 image processing toolkit with command-line automation and image I/O. It includes convolution filters, max pooling, kernel based filters, flexible output handling, and unit-tested components built with CMake.

c-sparse-matrix-engine

With this engine a 2D sparse matrix data structure is implemented with graph traversal capabilities using Breadth First Search (BFS) while also detecting cycles in the BFS tree. Basic operations for nodes include create, insert, delete.

Publications

Skin Cancer Identification on Edge Devices Exploiting Kolmogorov Arnold Networks

G. Venitourakis, M. Patsi, K. Charalampeli, C. Kachris, and D. Reisis
Emerging Tech Conference on Edge Intelligence, Athens, Greece, October 2025.

This publication presents a hardware-efficient approach to skin cancer detection using Kolmogorov-Arnold Networks (KANs) deployed on edge devices. The work demonstrates the application of advanced neural network architectures in practical medical imaging applications with optimized computational requirements.
