# Personal Website

## Overview

This repository hosts my personal website using GitHub Pages. This site serves as my online portfolio and personal hub on the web.

## About

This website showcases my work, projects, and professional information. It's a central place where you can learn more about what I do and see examples of my portfolio.

## Template

This website is built upon the **[Strata](https://html5up.net/strata)** free template by HTML5 UP. The Strata template provides a clean, modern, and responsive design that works great for personal portfolios.

## Hosting

This repository is hosted using **GitHub Pages**, which provides free static site hosting directly from this GitHub repository. Any changes pushed to this repository will automatically be deployed to the live website.

## Contact Form

The contact form on the website is powered by **[Formspree](https://formspree.io/)**, a free service that allows static websites to receive form submissions via email. When visitors fill out and submit the contact form, their message is automatically sent to the configured email address. This eliminates the need for a backend server while keeping the site fully static and hosted on GitHub Pages.
