Overview

Caves of Chaos is a Java roguelike RPG where you choose a class, explore procedurally generated cave floors, fight enemies, collect loot, and descend toward a final boss encounter. The objective is to survive the labyrinth and defeat the Medusa of Chaos.

Gameplay Details

Class Choice: Start as either a Wizard (ranged spellcaster) or a Duelist (melee fighter with balanced combat abilities).

Procedural Caves: Each level is generated with cellular automata, creating a fresh cave layout in every run and improving replayability.

Boss Progression: The Medusa of Chaos keeps persistent health across transitions, so each encounter contributes to the final victory.

Main Entry Point

The game starts in src/CavesOfChaos.java. It loads XML configuration and assets, parses class/name arguments, initializes the player and GameState, builds the Swing interface, and handles cleanup on exit.

Core Features

  • Procedurally generated cave levels for every run
  • Real-time combat with class-specific abilities and cooldowns
  • Item collection and inventory management
  • Class-specific weapons and abilities
  • Persistent-health final boss level
  • Modular and extensible architecture

How to Play

Requirement: Java 24 or higher.

Quick Play (Windows): compile and run with defaults (Wizard, Player1).

run.bat

Quick Play with custom class/name:

run.bat wizard Gandalf
run.bat duelist Conan

Build distributable JAR:

build-jar.bat
java -jar dist/CavesOfChaos.jar wizard PlayerName

Example JAR runs:

java -jar dist/CavesOfChaos.jar wizard Gandalf
java -jar dist/CavesOfChaos.jar duelist Conan
